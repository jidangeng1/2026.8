# 🎓 学分绩点计算器

一个纯前端、本地运行的学分绩点（GPA）计算工具。手机、电脑浏览器均可使用，**数据只在本机计算，不会上传服务器**。

## 功能

- **上传 Excel（自动识别）**：自动解析全部 Sheet，智能识别表头行、学分行、姓名/学号列、学生数据区，无需手动配置
  - 识别并排除"个人成绩单" Sheet（如学校导出的个人明细，含官方 GPA），不混入班级计算
  - 当前班级人数自动统计；转出学生（姓名带 `<` 等标记）自动归并
- **表格可视化**：整张成绩表可视化渲染，课程列表头高亮显示，点击勾选/取消；学分自动识别，可点击就地修改；灰色列为学号/姓名/平均分等，不参与计算
- **选择学生**：搜索框快速找人；支持单选（"只算我"，默认填你的名字）或多选（"全班"）；当前班级/全部学生两种范围
- **手动录入**：直接填写或从剪贴板粘贴（Tab/逗号分隔），动态增删行
- **结果展示**：单人 → GPA 总览卡片 + 逐课明细 + 学期筛选；多人 → 全班 GPA 排名对比表（含每学期 GPA 列），点击某学生看明细
- **导出 Excel**：单人导出总览 + 明细；全班导出「汇总表（每人一行）+ 每人明细 Sheet」

## 计算公式

| 项目 | 规则 |
| --- | --- |
| 单科绩点 | 成绩 ≥ 60 → `(成绩 ÷ 10) − 5`；成绩 < 60 → `0` |
| 学分绩点 | 单科绩点 × 学分数 |
| GPA | Σ学分绩点 ÷ Σ学分数 |
| 加权平均分 | Σ(成绩 × 学分) ÷ Σ学分 |

挂科课程绩点为 0，但学分计入分母。

## 本地运行

```bash
npm install     # 安装依赖（仅首次）
npm run dev     # 开发模式，浏览器打开 http://localhost:5173
```

## 构建生产版本

```bash
npm run build   # 产物输出到 dist/
npm run preview # 本地预览构建产物
```

构建产物 `dist/index.html` 是**单个自包含文件**（已用 `vite-plugin-singlefile` 内联所有 JS/CSS），**双击即可直接使用**，无需任何环境。可直接发给别人用，或部署到任意静态托管（GitHub Pages、Vercel、Nginx 等）。

分享给别人：
```bash
# 构建后产物在 dist/index.html（约 530KB 单文件）
npm run build
# 可将其重命名打包发给同学，双击即用
```

> 已生成一个含使用说明的分享包：`绩点计算器.zip`（桌面 gpa-calculator 目录内）。

## 验证

npm run verify  # 运行核心计算逻辑单元测试
